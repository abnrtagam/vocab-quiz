# Filipino-English Vocabulary Quiz

**Name:** Abner S. Tagam Jr.
**Section:** BSIT3R10

## Description

A command-line Python quiz that tests your knowledge of Filipino-to-English vocabulary. The program displays a Filipino word and asks you to type its English meaning. Questions are shuffled each run, you can type `?` for a hint, and your final score is displayed at the end.

## How to Run

1. **Install Python 3.8+** — download from [python.org](https://www.python.org/downloads/) if you don't have it.
2. **Clone the repository:**
   ```bash
   git clone https://github.com/abnrtagam/vocab-quiz.git
   ```
3. **Navigate to the project folder:**
   ```bash
   cd vocab-quiz
   ```
4. **Run the quiz:**
   ```bash
   python vocab_quiz.py
   ```
5. Type your answer in English, or type `?` for a hint.
